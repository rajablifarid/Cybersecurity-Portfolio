# HTB Machines

This section contains my practical work from Hack The Box Machines.

The purpose is to improve my practical skills in system enumeration, network services, web application security, Linux and Windows security, and vulnerability analysis.

## Machines

| Machine | Operating System | Difficulty | Status |
|---|---|---|---|

## Learning Objectives

- Practice network and service enumeration.
- Analyze web applications and identify security vulnerabilities.
- Understand common attack techniques and their security impact.
- Practice Linux and Windows security concepts.
- Develop practical skills relevant to Blue Team and SOC operations.

## Documentation

Each machine has its own directory containing:

- Lab report
- Tools and commands
- Enumeration results
- Key findings
- Security observations
